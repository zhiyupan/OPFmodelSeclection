# Intermediate Results

`01_validation_batch_full_run_records.json` stores the complete historical recommendation process for all 54 requirements. It can be used to audit and reconstruct the current Top-3, but the legacy snapshot lacks the prompt/model fingerprints required by the new code and therefore cannot be used directly as a resumable cache for the current workflow. Rerunning the workflow calls the API and generates new records with the current fingerprints; this file is not the final score. If the API fails during a new resumable run before any result succeeds, the program retains this last valid snapshot rather than overwriting it with empty JSON/CSV files. Subsequent saves also use atomic replacement through temporary files in the same directory, preventing interruptions from leaving partially written files.

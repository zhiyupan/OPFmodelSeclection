# Input Notes

- `01_user_requirements.csv`: the sole authoritative requirement table for the online-recommendation workflow, containing 54 natural-language requirements. R01–R19 are enterprise requirements, and M01–M35 are paper-motivation requirements. Each row stores the author/organization, title, year, DOI/official link, in-project source, page or section, evidence grade, and concise rationale for one primary citation. The 19 R requirements also contain a set of `report_source_*` fields recording the publication page, PDF, local file, access date, license, and evidence role of the corresponding real-world report. The report fields for R14–R16 and R19 are explicitly marked as supplementary background, while academic papers remain the primary citations.
- The GUI requirement selector, online-recommendation Notebook, and batch Validation share this single CSV. The GUI can load any entry as an example and always allows users to enter or rewrite any natural-language requirement directly.
- `02_requirement_source_traceability/`: unified source-traceability material for the 54 requirements. Within it, `01_enterprise_grid_reports/` stores 28 enterprise/grid reports and the master source manifest `enterprise_grid_reports_manifest.csv`; `02_paper_corpus_manifest.csv` is a byte-identical synchronized copy of the authoritative paper manifest from workflow 01. Citation columns in the 54-requirement CSV bind directly to these materials; the recommendation program does not parse the contents of the reports or manifests themselves.
- The four original 55-category requirement-design tables were neither program inputs nor capable of one-to-one correspondence with the R/M cases. They have therefore been removed, and no second requirement directory is retained.
- The knowledge graph is read directly from the sole output of workflow 01; this directory does not duplicate it.

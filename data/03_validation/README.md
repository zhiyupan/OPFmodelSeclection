# 03 Validation Workflow

This directory provides unified validation for the first two workflows:

1. Whether online recommendation ranks the correct paper models in the Top-3.
2. Whether the fields of the fixed 35-paper PaperModel benchmark generated by paper ingestion agree with the human records. The newly added P036 entry is not yet part of this validation benchmark.

The main entry point is the GUI's `Validation` page; the batch entry point is `src/Validation2.0.ipynb`.

## 01_input

- `01_recommendation_human_gold/recommendation_human_gold_54_requirements.csv`: the only machine-readable human Gold for recommendation validation. Each of the 54 requirements occupies one row; enterprise requirements store unordered acceptable candidate sets, while Motivation requirements store ordered models and nDCG relevance weights.
- `02_paper_ingestion_human_gold/01_records/`: 35 human-authored PaperModel Markdown records for the fixed validation benchmark, which are read directly by paper-ingestion quality validation. P036 is not yet included.
- Cross-workflow inputs: workflow 02's authoritative CSV containing 54 requirements and its Top-3 CSV, together with workflow 01's knowledge graph. The 28 enterprise reports are located in workflow 02's source-traceability directory. The authoritative manifest for the current 36-paper corpus is located in workflow 01, while workflow 02 retains only a reference mirror protected by a synchronization check. The fixed paper-ingestion validation benchmark still covers 35 papers and excludes P036. Validation no longer duplicates these materials.

## 02_intermediate

- `01_llm_validation_cache/`: English-translation caches and LLM factual-judgment caches for the fixed 35-record Gold benchmark. P036 is not yet included. The program reads these files directly; deleting them requires new API calls.
- `02_semantic_embedding_model_cache/`: an approximately 458 MB multilingual sentence-embedding model. The program reads it directly. It can be downloaded again when online, but it must be retained for offline execution; the model files are excluded by `.gitignore`.

## 03_output

- `01_recommendation_validation/`: 54 per-requirement scores and 2 aggregate metrics.
- `02_paper_ingestion_validation/`: retains only three clearly structured tables—980 field-level semantic-similarity details, 980 field-level factual-accuracy details, and a one-row overall summary. If papers cannot be matched one-to-one with the human Gold, the program raises an error directly and no longer generates an empty `issues.csv`.

Validation does not duplicate the Gold, Top-3 results, or knowledge graph, so each type of data has a single authoritative location.
